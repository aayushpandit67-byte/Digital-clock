# Digital Clock

A simple and responsive **Digital Clock** built using **HTML, CSS, and JavaScript**.
This project displays the current time in real-time with a clean UI and smooth updates every second.

---

## Features

* Real-time clock updates
* Responsive design
* Simple and clean user interface
* Built with pure HTML, CSS, and JavaScript
* Beginner-friendly project

---

## Technologies Used

* **HTML5** – Structure of the clock
* **CSS3** – Styling and layout
* **JavaScript** – Dynamic time updates

## ⚡ How It Works

The JavaScript code:

1. Gets the current time using the `Date()` object
2. Extracts hours, minutes, and seconds
3. Updates the clock every second using `setInterval()`
